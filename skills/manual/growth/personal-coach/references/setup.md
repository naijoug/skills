# First-time Setup

**Trigger:** The user requests a persistent roadmap or setup. A missing file alone does not require onboarding for a one-off question.

**Flow:**

1. Look for `growth-roadmap.md` at `~/.personal-growth/growth-roadmap.md` (stable home location, independent of current project directory).
2. Reuse the goals, available time and self-assessment already supplied. Ask only for missing inputs that change the plan. For a requested full assessment, useful inputs are:
   a. Ask them to self-assess each of the 6 pillars on a 1-5 scale
   b. Ask for their growth goals (short-term: 3 months, long-term: 1 year)
   c. Ask how much time they can invest daily and weekly
3. Generate `growth-roadmap.md` using [state format](state-format.md).
4. Recommend the first week's practice plan based on their priorities.

Persist only actual plan changes or confirmed progress when tracking is requested
or already established. Do not create or rewrite a roadmap for a one-off answer.
