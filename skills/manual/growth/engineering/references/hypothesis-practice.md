# Human hypothesis practice

Use when the user explicitly wants an agent-assisted task to train their judgment.
Before the learning exercise's edit, capture the learner's observation, hypothesis,
what would disprove it, and verification method. Reuse a hypothesis already given;
if none exists, ask the learner for it instead of fabricating human reasoning.
Independent authorized observation can continue.

Bound the change by the task's paths and desired outcome. Compare the agent's
proposal with the hypothesis, then let actual verification decide whether to
continue, narrow or revise the hypothesis. Distinguish a failed test from missing
verification; do not automatically undo useful work or switch to an unrelated task.

A compact note, when requested:

- Observation and human hypothesis before the edit.
- Agent proposal and assumptions.
- Verification command, result and whether it changed the hypothesis.
- What the learner accepted/rejected and the next smaller drill.

Use [the card example](hypothesis-card.md) only when a filled example helps. Commits,
publication and creating additional assets require the task's existing authority.
