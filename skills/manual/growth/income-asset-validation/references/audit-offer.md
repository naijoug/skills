# Fixed-scope AI coding audit

Use only when this is the selected offer, not as the default for every income idea.
Agree on buyer, repository/workflow, time budget, access and deliverable. A small
read-only audit can produce a short prioritized report, concrete verification
commands and one reusable template. Do not promise a fixed number of findings.

Inspect real evidence for change ownership, verification coverage, handoff quality
and failure recovery. Keep private proof separate from publishable summaries. Do
not require production credentials or alter production code for a read-only offer.

For output shape, see [sample report](ai-coding-audit-sample-report.md). Its sample
findings are hypothetical, not evidence of an actual client result. Adapt controls
to the repository; do not apply every sample gate to every task.
