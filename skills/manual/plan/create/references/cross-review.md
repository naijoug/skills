# Compare independent plan reviews

Use only when the user requests multiple reviews and the host permits delegation.
Give reviewers the same plan, code snapshot, scope and constraints; avoid supplying
other reviewers' conclusions. Record what each reviewer actually inspected.

Reconcile findings against code. Agreement is a prioritization signal, not proof;
a unique finding may be valid and several agents may share the same error. Resolve
disagreements with evidence rather than automatically adopting the strictest verdict.

Return confirmed findings, dismissed claims with reasons, remaining uncertainty
and the resulting verdict. Save separate reports only when requested or required
by the project. Never claim an independent review that did not run.
