# Routing examples

These are candidate-selection fixtures, not authorization to execute their actions.

## Positive (Chinese)

- "根据这张已有产品截图写一个高保真改版提示词，保留真实实体和操作流程。"
- "把这个页面的现状和工作流整理成一份可复用的 mockup brief，方向是突出阅读。"

## Positive (English)

- "Write a mockup prompt for the supplied product screen that preserves its workflow and explores one focused direction."
- "Turn this existing dashboard into a high-fidelity design brief with real labels, layout constraints and a clear hero task."
