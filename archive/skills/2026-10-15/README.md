# Archived personal skill sources

These 18 packages retain the exact working-tree bytes captured on 2026-10-15,
including earlier uncommitted fixes. Only `SKILL.md` and `skill.yaml` were renamed
to `SKILL.md.disabled` and `skill.yaml.disabled`; other resources remain intact.
They are source archives, not active skills, and historical references may point
to retired names. Do not install this archive as a collection.

See [manifest.json](manifest.json) for original paths, replacements and SHA-256
checksums, and [the migration map](../../../docs/skills-consolidation-2026-10-15.md)
for current entrypoints. To restore one package, copy it to its unoccupied original
path, restore the two filenames, validate it and explicitly reinstall that skill.
Keep the archive intact so restoration remains reversible.
