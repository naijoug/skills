Claude Code 是 Anthropic 推出的官方命令行工具 (CLI)，用于将 Claude 直接集成到开发者的终端工作流中。以下是截至已知信息的主要功能和更新：

### Key Features / 核心功能

- **Agentic Coding (智能编程代理):** Claude Code 作为一个 AI 编程代理运行在终端中，可以理解整个代码库的上下文，执行代码编辑、运行命令、搜索文件等操作
- **Multi-file Editing (多文件编辑):** 支持跨多个文件的协调编辑，理解项目结构和依赖关系
- **Tool Use (工具使用):** 内置多种工具包括 Bash 命令执行、文件读写、代码搜索 (Grep/Glob)、WebSearch、WebFetch 等
- **MCP Support (MCP 协议支持):** 支持 Model Context Protocol，可以通过 MCP 服务器扩展功能，连接外部工具和数据源
- **CLAUDE.md Configuration:** 支持通过项目级和用户级 CLAUDE.md 文件自定义行为和指令
- **Git Integration (Git 集成):** 深度集成 Git 工作流，支持提交、PR 创建、代码审查等
- **Background Tasks (后台任务):** 支持后台运行长时间任务并在完成时通知
- **Custom Slash Commands (自定义斜杠命令):** 支持通过 `.claude/commands/` 目录定义自定义命令
- **Skill System (技能系统):** 支持通过 skill 机制扩展 Claude Code 的能力

### Known Updates (as of training cutoff) / 已知更新

1. **Claude Code Launch (2025 初):** Anthropic 正式发布 Claude Code CLI 工具，支持 macOS 和 Linux
2. **Model Upgrades:** Claude Code 持续升级底层模型，从 Claude 3.5 Sonnet 到 Claude 3.7 Sonnet，再到更新的模型版本
3. **Extended Thinking (扩展思考):** 支持扩展思考模式，让模型在复杂任务上有更深入的推理
4. **Permissions System (权限系统):** 完善的权限控制系统，用户可以精细控制工具的使用权限
5. **SDK & API Access:** Claude Code Agent SDK 允许开发者以编程方式使用 Claude Code 的能力
6. **Custom Instructions via CLAUDE.md:** 支持多层级的配置文件 (全局 `~/.claude/CLAUDE.md`、项目级、目录级)
